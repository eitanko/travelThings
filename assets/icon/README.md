# Logo sources

Vector masters for the app icon (1024×1024, full-bleed, no rounded corners — iOS applies the mask).

- `icon.svg` – default (light) icon
- `icon-dark.svg` – iOS 18 dark appearance
- `icon-tinted.svg` – iOS 18 tinted appearance (grayscale on black)
- `splash-icon.svg` – glyph only, transparent background

Export PNGs at 1024×1024 with no alpha channel (except the splash icon) before wiring into `app.json`.
